# 本次实测结果

日期：2026-09-22。版本：0.2.0。环境：Windows、Python 3.12.10、PySide6 6.8.3。

## 已验证

- 38 项自动测试通过：包括模型进程复用、并发请求串行处理、取消/超时/崩溃/错位响应后恢复、退出清理空闲进程、仅生成回复模式和候选编辑复制；原有数据隔离、脱敏、记忆、MCP 和 HTTP 测试继续通过。
- MCP 测试使用独立 stdio 服务，完成真实握手、工具发现、状态检查、消息游标分页；状态健康但数据库断开会被拒绝。
- 原生 Qt 窗口在 Windows 平台启动与关闭成功，中文界面和三栏布局完成截图检查。
- 目录模式 EXE 在中文部署路径运行成功：PATH 仅保留 Windows System32，去除 Python 环境变量，能启动、创建本地数据库、截图并正常退出；工具自身使用包内 Python。
- Laya 0.3.5 + 固定多语言 checkpoint 在 CPU 上真实加载；桌面适配器通过 JSONL 子进程取得非回退决策。
- 打包 EXE 的诊断模式在隔离 PATH 下成功启动 MCP 测试服务及外部 Laya Python，并加载真实模型，退出码为 0。MCP 一侧仍是测试数据，不能替代真实微信数据库验收。
- 30 条合成中文案例全部真实推理，无 fallback。
- 桌面实际 JSONL 适配器连续三次调用：**25.797 秒、0.500 秒、0.516 秒**，确认复用同一进程，关闭后进程已退出。只测本地判断，不包含生成接口耗时；首次冷加载仍较慢。

## 模型效果限制

同一批 30 条开发合成样例：情绪保持 **18/30**，意图从 0.1.0 的 **5/30** 提升到 **12/30**。此次改变是将意图问题改为中文，并单独针对对方消息判断，避免“帮我回复”等操作要求参与意图分类。多轮输入保留目标消息之前的已知方向对话，不把后续自己的回复作为目标。

对比实验：英文问题 + 完整状态的意图匹配为 5/30；英文问题 + 单条消息为 7/30；中文问题/解释 + 原英文类别键为 12/30；连类别键也改中文反而只有 8/30，因此未采用。情绪独立改中文未改善，继续保留原方式。以上是用于选择实现的开发集分数，不是独立测试集结果。

本结果不代表生产准确率，也不是独立人工评审。当前 Laya 判断只适合作为实验性信号；界面明确标注，生成提示要求以原消息为准，不机械沿用判断。现阶段不应宣称中文意图分析已经达到可靠水平。后续需要独立标注集、领域适配或更换判断模型。
